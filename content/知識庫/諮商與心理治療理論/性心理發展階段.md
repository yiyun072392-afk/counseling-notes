title: "性心理發展階段"
---

[[精神分析治療 Psychoanalytic therapy]]的概念之一，也是[[心理社會發展階段]]之前的發展階段理論。
Freud 關注生物層面的「身體快感、欲望與衝突」如何參與人格形成；艾里克森關注社會層面的「不同生命時期，如何透過與他人、社會的互動發展自我」。

| 階段                 | 約略時期     |
| ------------------ | -------- |
| 口腔期（oral stage）    | 約0～1歲    |
| 肛門期（anal stage）    | 約1～3歲    |
| 性蕾期（phallic stage） | 約3～6歲    |
| 潛伏期（latency stage） | 約6～12歲   |
| 性器期（genital stage） | 12～18歲之後 |
## 口腔期
1. 發展重點：滿足口腔的慾望。
2. 生物機制：嘴是主要的快感來源，透過吸吮、吞嚥、咬等活動獲得滿足。
3. 與照顧者的關係：餵食與斷奶也讓滿足和照顧者的關係連在一起。如果沒有獲得滿足，有可能會因為這個階段的慾望受到阻礙而[[固著]]於口腔期，發展出貪婪、貪得無厭的心，同時也會無法信任他人，無法與他人建立親密關係。
4. 發展問題：為何佛洛伊德認為口腔期受阻，固著於口腔期會導致人無法信任他人，無法建立親密關係？因為口腔期藉由照顧者哺育自己，滿足自己，如果這個階段的照顧者無法滿足個體，並且因為口腔慾望受到阻礙而固著，個體會認為任何他者都將如同自己的照顧者一般無法信任。
## 肛門期
1. 發展重點：形塑主要性格，主要發展任務為學習獨立與表達憤怒和攻擊等負面情緒。
2. 生物機制：快感集中於排泄與保留糞便。
3. 與照顧者的關係：肛門期的管教之所以被認為會影響人格，是因為排便訓練讓孩子第一次強烈面對：自己的身體與滿足，要如何配合他人的要求。父母要求孩子按時、在正確地方排便，孩子則可能想依照自己的身體感受與意願。衝突圍繞著「由誰決定、何時交出、能否拒絕」，因此被連結到後來的控制、服從、固執與秩序感。
4. 發展問題：如果父母管教過於嚴格，有可能會因為固著於肛門期學會如何藉由控制自己進而反抗父母的方式，衍生出下列性格。
	- 延續憋便傾向：保留、不願交出、堅持由自己決定。
	- 反向作用：難以接受自己生產的髒污或混亂，於是發展出強烈的整潔與秩序要求。
	- 昇華：原來的欲望轉向其他可被社會接受的活動或目標。
## 性蕾期
1. 發展重點：注意力轉向生殖器、身體差異與家庭中的愛慾及競爭。古典理論把伊底帕斯情結放在[[伊底帕斯期]]，並以認同父母來說明衝突的處理。
2. 生物機制：發現自己除了口腔的飲食和肛門的控制之外，性器官也可以產生快感。
3. 與照顧者的關係：
	1. 男孩渴望得到母親的愛，女孩渴望得到父親的愛。
	2. 男孩對母親或女孩對父親有了成婚交配的亂倫慾望，萌生想要殺害並取代同性照顧者的幻想，但是自己也知道這個慾望不能滿足，不僅自己會失去照顧者，甚至同性照顧者可能會懲罰自己：男孩認為具有陰莖的父親閹割了沒有陰莖的母親，如果這個慾望被父親知道，具有力量與權柄的父親也有可能閹割自己；女孩雖然渴望成為母親，但是因為缺乏跟父親一樣的陰莖而感到無力。
	3. 佛洛伊德認為解決方式是認同原先被視為敵對的同性照顧者。男孩認同自己所害怕的，具有力量、權柄與陰莖的父親，期待總有一天父親也會給予自己一樣的東西好讓自己夠格與母親成婚；而女孩雖然無法成為具有陰莖的人，卻依然同樣會認同母親，好擁有一個具有陰莖的人，生出陰莖更大更好的嬰兒，補償自己沒有陰莖的缺憾。
4. 發展問題：兒童會在這個階段體驗到渴望、性慾、禁忌、嫉妒、踢出家門和愛恨交織的焦慮。此階段父母的回應方式會影響兒童對於自己的性慾以及如何看待關係定位。
## 潛伏期
性欲的直接表現相對減弱，或受到壓抑、昇華；更多活動轉向學習、同儕與社會技能。「潛伏」不代表性欲完全消失。
## 性器期
性蕾期不同的欲望成分，在生殖器主導下重新組織；理論理想是發展出能兼顧自己與伴侶滿足的成熟親密關係。在社會壓抑性慾的條件下，個體有可能延續潛伏期的方式，將性慾昇華為其他領域的成就。
