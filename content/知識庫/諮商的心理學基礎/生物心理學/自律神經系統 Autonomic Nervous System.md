## 恐慌的不是他的心，是他的腎上腺

這是一篇 2018 年發表的[病例報告](https://doi.org/10.1530/EDM-17-0176)，他的腫瘤叫嗜鉻細胞瘤（pheochromocytoma）。

他的發作有三個特徵：

- 心臟狂跳
- 頭痛
- 全身冒汗

這三件事，是身體遇到危險時的標準反應，也是嗜鉻細胞瘤教科書上的「三大症狀」。

負責這種反應的，是自律神經系統裡的交感神經。

平常只有遇到危險，交感神經才會叫腎上腺釋放腎上腺素，讓全身進入備戰狀態。

他的腫瘤長在腎上腺中間的腎上腺髓質，沒有危急壓力也會不定時大量釋放這些荷爾蒙。

所以，他的身體一次又一次「以為」自己遇到危險。

恐慌發作本來就是交感神經的大爆發，兩者看起來幾乎一模一樣，這就是醫師誤診他十三年的原因。

要看懂這件事，先要看懂自律神經系統怎麼運作。

## 兩個神經元接力，傳令到內臟

自律神經系統（autonomic nervous system）是周圍神經系統的一部分，負責調節心跳、消化、呼吸、排尿這些維持身體內在平衡的內臟功能。

「自律」不是指我們自己規律生活，而是神經系統會自己管理自己，不需要、也沒辦法用意識控制。

他再怎麼告訴自己「不要怕」，心跳還是停不下來。

自律神經從中樞到目標器官，通常要經過[兩個神經元](https://www.britannica.com/science/human-nervous-system/The-autonomic-nervous-system)接力：

1. 節前神經元（preganglionic neuron）：細胞本體在腦幹或脊髓裡。
2. 節後神經元（postganglionic neuron）：細胞本體在中樞神經系統之外，聚集在一個個自律神經節（autonomic ganglia）裡，再由它的軸突連到目標器官。

兩個神經元在神經節裡用突觸相連。

唯一的例外，就是故事裡出問題的[腎上腺髓質](https://openanesthesia.org/autonomic_neurotransmitters)：

腎上腺髓質直接接在節前神經元上，收到命令就把腎上腺素和正腎上腺素釋放到血液裡，讓交感神經的反應擴及全身。

腎上腺髓質本來要等交感神經下令。

嗜鉻細胞瘤跳過這個命令，自己放出荷爾蒙。

## 交感神經：全身備戰

交感神經讓身體備戰，就是故事裡一次又一次全開的那一套。

- 節前神經元在脊髓的胸段到腰段，所以又稱「胸腰段出口」（thoracolumbar outflow）。
- 分布到全身。
- 和戰鬥或逃跑（fight or flight）有關：心跳加快、瞳孔放大、支氣管擴張、腸胃蠕動減少。

>     - [ ] 腦幹和脊髓薦段｜這是副交感神經。

>     - [ ] 沒有變化｜交感神經會讓支氣管擴張。

## 副交感神經：全身而退

副交感神經負責備戰之後的收尾，讓身體休息。

- 節前神經元在[[腦幹 Brainstem|腦幹]]和脊髓的薦段，所以又稱「顱薦段出口」（craniosacral outflow）。
- 腦幹這一段走的是第三、七、九、十對腦神經。
    - 第十對迷走神經（vagus nerve）分布到胸腔和腹腔的器官；薦段則支配膀胱、生殖器官和下段腸道。
- 神經節靠近或就在目標器官的壁內。
- 和休息與消化（rest and digest）有關：心跳減慢、瞳孔縮小、腸胃蠕動增加。

>     - [ ] 動眼神經｜動眼神經控制眼睛。

>     - [ ] 靠近脊髓｜交感神經的神經節多在脊髓附近。
>     - [ ] 大腦裡｜神經節在中樞神經系統之外。

## 彼此拮抗的交感與副交感神經

| 項目 | 交感 | 副交感 |
| --- | --- | --- |
| 口訣 | 戰鬥或逃跑 | 休息與消化 |
| 節前神經元的位置 | 脊髓胸段到腰段 | 腦幹和脊髓薦段 |
| 分布 | 全身 | 頭部和體腔內的器官 |
| 節前傳導物質 | 乙醯膽鹼 | 乙醯膽鹼 |
| 節後傳導物質 | 正腎上腺素，汗腺例外 | 乙醯膽鹼 |

交感神經的節後神經元大多釋放[正腎上腺素](https://www.amboss.com/us/knowledge/autonomic-nervous-system)，只有汗腺等少數例外用乙醯膽鹼。

乙醯膽鹼作用在菸鹼型（nicotinic）或蕈毒鹼型（muscarinic）受體上。

正腎上腺素作用在 α 或 β 腎上腺素受體上。

各器官的反應：

| 器官 | 交感 | 副交感 |
| --- | --- | --- |
| 瞳孔 | 放大 | 縮小 |
| 心臟 | 心跳加快、收縮變強 | 心跳減慢 |
| 支氣管 | 擴張 | 收縮 |
| 腸壁 | 蠕動減少 | 蠕動增加 |
| 腸道括約肌 | 收縮 | 放鬆 |
| 膀胱逼尿肌 | 放鬆 | 收縮 |
| 膀胱的內括約肌 | 收縮 | 放鬆 |
| 男性生殖器 | 射精 | 勃起 |
| 汗腺 | 出汗 | — |
| 腎上腺髓質 | 分泌腎上腺素 | — |

各器官的反應整理自[明尼蘇達大學的解剖教材](https://vanat.ahc.umn.edu/ans/pages/popUpPgs/ansInnervateTable.html)。

## 交感踩油門，副交感踩煞車，有時還要輪流踩

交感神經像油門，副交感神經像煞車。

緊急狀況時交感神經踩油門，讓身體迎接挑戰。

挑戰過後，副交感神經踩煞車，讓身體緩和下來。

故事裡的他之所以發作幾分鐘就恢復，是因為血液裡的腎上腺素退去之後，副交感神經又把身體拉回平靜。

很多器官同時受兩者支配，而且作用相反，這叫雙重支配（dual innervation）。

但這個比喻有限制：

不是每個器官都有兩邊的支配，例如多數的血管只有交感神經支配。

兩者功能相反，有時候卻要按照順序互相配合。

### 勃起靠副交感，射精要三套神經合作

- 勃起：主要靠薦段的副交感神經。
- 排精：射精的第一階段，精液進入尿道，由交感神經接手。
- 射精：比勃起複雜，交感、副交感和體神經都有[參與](https://pubmed.ncbi.nlm.nih.gov/21967393/)。

所以兩者的協調出問題，可能影響性功能。不過男性性功能障礙的[成因很多](https://pmc.ncbi.nlm.nih.gov/articles/PMC8547275)，神經、血管、荷爾蒙都可能是原因。

### 憋尿靠交感和意識，排尿靠副交感

膀胱的活動分成[儲尿和排尿](https://www.msdmanuals.com/professional/genitourinary-disorders/voiding-disorders/overview-of-voiding)兩個階段：

- 儲尿：交感神經讓逼尿肌放鬆、內括約肌收縮；受意識控制的外括約肌也維持收縮，它由[[軀體神經系統 Somatic Nervous System|軀體神經]]裡的陰部神經支配。所以憋尿不只是交感神經的事，還有意識參與。
- 排尿：決定要排尿後，副交感神經讓逼尿肌收縮、括約肌放鬆。[[額葉 Frontal Lobe|額葉]]也有一個抑制排尿的中樞，幫忙決定什麼時候可以排。

壓力大的時候，身體常同時出現好幾種自律神經反應，例如緊張時肚子不舒服、想上廁所。

## 腸神經：自我管理的腸道

除了交感和副交感，也有分類把[腸神經系統](https://meshb.nlm.nih.gov/record/ui?ui=D017615)視為自律神經的第三個分支。

它是嵌在消化道壁裡的兩層神經叢，管理消化道、胰臟和膽囊的功能。

它可以不靠腦和脊髓獨立運作，但也受交感和副交感神經影響，所以有人稱它為「第二個大腦」。

>     - [ ] 它負責思考｜它負責管理消化道。
> 2. 腸神經系統嵌在哪裡？
>     - [x] 消化道壁裡｜由肌間神經叢和黏膜下神經叢組成。
>     - [ ] 脊髓裡｜它在消化道壁裡。
>     - [ ] 皮膚裡｜它管理的是消化道、胰臟和膽囊。

## 腦幹負責即時反射，下視丘負責長期調節

自律神經不受意識控制，但它有自己的指揮中心，分成兩層。

第一層在腦幹和脊髓，負責反射。

[[腦幹 Brainstem#延腦 Medulla Oblongata|延腦]]裡的孤束核（nucleus of the solitary tract）是[內臟感覺的主要入口](https://vanat.ahc.umn.edu/ans/pages/CNScontrol.html)，它接收血壓、心跳等訊號，再交給附近的神經核發出交感或副交感的命令。

這一層的反射[以毫秒計](https://doi.org/10.3389/fnins.2014.00440)。例如：血壓突然升高，孤束核收到訊號，就讓心跳慢下來。

第二層是[[間腦 Diencephalon#下視丘 Hypothalamus|下視丘]]，負責幾分鐘到幾天的長期調節。

下視丘的室旁核（paraventricular nucleus）是[中樞自律神經網路裡最重要的神經核](https://nba.uth.tmc.edu/neuroscience/s4/chapter03.html)，它直接把命令送到腦幹和脊髓的節前神經元。

這整個網路和負責情緒的邊緣系統連結很密，所以人害怕的時候，心跳也會跟著加快。

一般的恐慌發作，命令就是從這兩層一路往下傳。故事裡的腫瘤卻不經過任何一層指揮，自己把荷爾蒙放進血液。

## 壓力來時，腎上腺素先，皮質醇後

身體面對壓力，靠的是[兩條路線](https://www.ncbi.nlm.nih.gov/books/NBK541120/)：

- 快的一條是「交感—腎上腺髓質軸」，簡稱 SAM 軸：交感神經命令腎上腺髓質把腎上腺素和正腎上腺素放進血液，讓心跳加快、血壓上升。
- 慢的一條是「[[間腦 Diencephalon#下視丘 Hypothalamus|HPA 軸]]」：下視丘、腦下垂體、腎上腺皮質一路接力，最後放出皮質醇。

壓力出現時，[交感神經先啟動，HPA 軸隨後才跟上](https://pmc.ncbi.nlm.nih.gov/articles/PMC6181794/)。

兩條路線的終點都在腎上腺，但用的是不同部位：髓質在內層，皮質在外層。

故事裡的腫瘤長在髓質，等於讓 SAM 軸這條快路不時自己啟動，所以他的發作來得又快又猛，幾分鐘就退去。

>     - [ ] HPA 軸｜HPA 軸要經過下視丘、腦下垂體、腎上腺皮質接力，比較慢。

## 自律神經失調，不等於自律神經受損

自律神經本身也會受傷。

糖尿病長期傷害周邊神經，常見的併發症之一就是自律神經病變，患者可能站起來就頭暈、腸胃蠕動變慢、排尿困難。

這類疾病在醫學上統稱自律神經功能障礙（dysautonomia），指的是自律神經本身的結構或功能出了問題。

台灣日常說的「自律神經失調」範圍更廣，常用來描述壓力下的心悸、失眠、腸胃不適，這些症狀不一定代表自律神經受損。

## 看到恐慌症狀，諮商師要先排除身體因素

故事裡的他，十三年來每個症狀都符合恐慌發作，真正的原因卻在腎上腺。

恐慌症的診斷本身就要求症狀不能用藥物或其他身體疾病解釋，例如甲狀腺機能亢進或心肺疾病。

[MSD 診療手冊](https://www.msdmanuals.com/professional/psychiatric-disorders/anxiety-and-stressor-related-disorders/panic-attacks-and-panic-disorder)也提醒，評估恐慌發作時要先排除身體的原因。

[嗜鉻細胞瘤](https://www.msdmanuals.com/professional/endocrine-and-metabolic-disorders/adrenal-disorders/pheochromocytoma)很少見，但它會一陣一陣地讓血壓飆高，抽血檢驗血漿中的游離變腎上腺素就能篩檢。

所以當個案的焦慮出現下面這些特徵，諮商師可以建議個案先做身體檢查：

- 發作找不到任何情境或想法的觸發。
- 發作時血壓明顯升高，或伴隨劇烈頭痛。
- 心理治療和藥物都沒有改善。
- 中年以後才第一次出現恐慌發作。

這個病例的[原始報告](https://doi.org/10.1530/EDM-17-0176)寫道：醫療團隊在他接受精神科治療十三年之後，才查出真正的原因。

## 總結

- 自律神經不受意識控制，負責調節內臟、血管和腺體。
- 命令通常靠兩個神經元接力，腎上腺髓質是例外，直接把荷爾蒙放進血液。
- 交感神經從胸腰段出發，負責戰鬥或逃跑。
- 副交感神經從腦幹和薦段出發，負責休息與消化，第十對迷走神經分布最廣。
- 兩者常常作用相反，但在性反應和排尿時要按順序互相配合。
- 腸神經系統嵌在消化道壁裡，可以獨立運作。
- 腦幹的孤束核負責毫秒級的反射，下視丘負責長期調節。
- 壓力反應分成快的 SAM 軸和慢的 HPA 軸，分別用到腎上腺髓質和皮質。
- 焦慮的身體症狀和自律神經疾病很像，評估時要先排除身體的原因。
