自律神經系統（autonomic nervous system，ANS）又稱自主神經系統，是周圍神經系統的一部分，負責調節心跳、消化、呼吸、排尿這些維持身體內在平衡的內臟功能。

自律指的不是我們用自己的意志力規律生活的意思，這裡的主角是神經系統自己會自我管理，不需要也無法用意識監管。

## 兩段式的神經傳遞 Preganglionic and Postganglionic Neurons

自律神經從中樞到目標器官，通常要經過兩個神經元接力：

1. 節前神經元（preganglionic neuron）：細胞本體在腦幹或脊髓裡。
2. 節後神經元（postganglionic neuron）：細胞本體在中樞神經系統之外，聚集在一個個「自律神經節」（autonomic ganglia）裡，再由它的軸突連到目標器官。

兩個神經元在神經節裡突觸相連。唯一的例外是腎上腺髓質：它直接連在節前神經元上，受到刺激時，會把腎上腺素和正腎上腺素釋放到血液裡，讓交感神經的反應擴及全身。

## 交感神經系統 Sympathetic Nervous System

- 節前神經元在脊髓的胸段到腰段（T1–L2），所以又稱「胸腰段出口」（thoracolumbar outflow）。
- 分布到全身。
- 和戰鬥或逃跑（fight or flight）有關：心跳加快、瞳孔放大、支氣管擴張、腸胃蠕動減少，讓身體進入備戰狀態。

> 1. 交感神經的節前神經元在哪裡？
>     - [x] 脊髓的胸段到腰段｜所以又稱胸腰段出口。
>     - [ ] 腦幹和脊髓薦段｜這是副交感神經。
>     - [ ] 大腦皮質｜節前神經元在腦幹或脊髓。
> 2. 交感神經興奮時，支氣管會怎麼樣？
>     - [x] 擴張｜讓身體進入備戰狀態。
>     - [ ] 收縮｜收縮是副交感神經的作用。
>     - [ ] 沒有變化｜交感神經會讓支氣管擴張。

## 副交感神經系統 Parasympathetic Nervous System

- 節前神經元在腦幹（第 III、VII、IX、X 對腦神經）和脊髓的薦段（S2–S4），所以又稱「顱薦段出口」（craniosacral outflow）。其中第 X 對腦神經就是迷走神經（vagus nerve），分布到胸腔和腹腔的器官；薦段則支配膀胱、生殖器官和下段腸道。
- 分布在頭部和體腔內的器官。神經節靠近或就位在目標器官的壁內。
- 和休息與消化（rest and digest）有關：心跳減慢、瞳孔縮小、腸胃蠕動增加。

>     - [ ] 動眼神經｜動眼神經控制眼睛。
>     - [ ] 三叉神經｜三叉神經負責臉部感覺和咀嚼。
> 2. 副交感神經的神經節在哪裡？
>     - [x] 靠近或就在目標器官的壁內｜所以節後纖維很短。
>     - [ ] 靠近脊髓｜交感神經的神經節多在脊髓附近。
>     - [ ] 大腦裡｜神經節在中樞神經系統之外。

## 交感與副交感的對照 Comparison

| 項目 | 交感 | 副交感 |
|---|---|---|
| 口訣 | 戰鬥或逃跑 | 休息與消化 |
| 節前神經元的位置 | 脊髓胸段到腰段（T1–L2） | 腦幹和脊髓薦段（S2–S4） |
| 分布 | 全身 | 頭部和體腔內的器官 |
| 節前傳導物質 | 乙醯膽鹼 | 乙醯膽鹼 |
| 節後傳導物質 | 正腎上腺素（汗腺等少數例外是乙醯膽鹼） | 乙醯膽鹼 |

傳導物質作用在不同的受體上：乙醯膽鹼作用在菸鹼型（nicotinic）或蕈毒鹼型（muscarinic）受體；正腎上腺素作用在 α 或 β 腎上腺素受體。

各器官的反應：

| 器官 | 交感 | 副交感 |
|---|---|---|
| 瞳孔 | 放大 | 縮小 |
| 心臟 | 心跳加快、收縮變強 | 心跳減慢 |
| 支氣管 | 擴張 | 收縮 |
| 腸壁 | 蠕動減少 | 蠕動增加 |
| 腸道括約肌 | 收縮 | 放鬆 |
| 膀胱逼尿肌 | 放鬆 | 收縮 |
| 膀胱的內括約肌 | 收縮 | 放鬆 |
| 男性生殖器 | 射精 | 勃起 |
| 汗腺 | 出汗 | — |
| 腎上腺髓質 | 分泌腎上腺素 | — |

> 2. 副交感神經對瞳孔的作用是什麼？

>     - [ ] 放大｜放大是交感神經的作用。
>     - [ ] 沒有作用｜瞳孔同時受兩者支配。

## 拮抗，也要合作 Antagonism and Cooperation

交感神經像油門，副交感神經像煞車：緊急狀況時交感神經亢奮，讓身體迎接挑戰，挑戰過後再由副交感神經踩煞車，讓身體緩和下來。很多器官同時受到兩者支配，而且作用相反，這叫雙重支配（dual innervation）。

但這個比喻有限制。不是每個器官都有兩邊的支配，例如多數的血管只有交感神經支配，勃起是副交感神經支配血管的少數例外。

它們雖然彼此功能拮抗，此消彼漲，但有時候還是要按照順序互相配合。

### 例子一：男性的性反應

勃起主要靠副交感神經（薦段 S2–S4），之後射精的第一階段「排精」（emission，精液進入尿道）則要由交感神經接手。射精比勃起更複雜，交感、副交感和體神經都有參與。所以交感與副交感的協調出了問題，可能影響性功能；不過男性性功能障礙的成因很多，神經、血管、荷爾蒙都可能是原因，不能只歸因於自律神經。

### 例子二：排尿

膀胱的活動分成儲尿和排尿兩個階段：

- 儲尿（憋尿）：交感神經讓逼尿肌放鬆、內括約肌收縮；同時，受意識控制的外括約肌（由體神經的陰部神經支配）也維持收縮。所以憋尿不只是交感神經的事，還有意識的參與。
- 排尿（上廁所）：決定要排尿後，副交感神經讓逼尿肌收縮，括約肌放鬆。額葉也有一個抑制排尿的中樞，幫忙控制什麼時候可以排。

壓力大的時候，身體常會同時出現好幾種自律神經反應，例如緊張時肚子不舒服、想上廁所（所謂「肚子裡有蝴蝶」）。這也是一種自主神經失調的樣子：明明很緊張，卻還是想尿尿。

## 腸神經系統 Enteric Nervous System

除了交感和副交感，也有分類把腸神經系統（enteric nervous system）視為自律神經的第三個分支。它是嵌在消化道壁裡的兩層神經叢（肌間神經叢和黏膜下神經叢），管理消化道、胰臟和膽囊的功能。它可以不靠腦和脊髓獨立運作，但也會受到交感和副交感神經的影響，所以有人稱它為「第二個大腦」。

>     - [ ] 它長在腦裡｜它嵌在消化道壁裡。
>     - [ ] 它負責思考｜它負責管理消化道。
> 2. 腸神經系統嵌在哪裡？
>     - [x] 消化道壁裡｜由肌間神經叢和黏膜下神經叢組成。
>     - [ ] 脊髓裡｜它在消化道壁裡。
>     - [ ] 皮膚裡｜它管理的是消化道、胰臟和膽囊。

## 自律神經失調 Autonomic Dysregulation

台灣的衛教常說「自律神經失調」，指交感與副交感的協調失當，常和長期壓力、焦慮、憂鬱有關。症狀遍布全身，例如心悸、胸悶、腸胃不適、頭暈、冒汗，而且各項檢查常常是正常的。

遇到這類症狀，建議先確認心臟、腸胃等器官沒有異常，再由神經內科（排除腦中風、帕金森氏症等神經疾病，並檢測自律神經）或身心科（評估壓力與情緒的因素）進一步評估。這頁只是學習筆記，不能取代醫師的評估。
